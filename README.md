# Audio to Good Score

**Intelligent Music Transcription & Reconstruction**  
Vom Klang zur musikalisch überzeugenden Partitur.

Ziel: Audioaufnahmen und/oder MIDI-Transkriptionen zu musikalisch schlüssigen, gut klingenden MIDI-Dateien und lesbaren MusicXML-Partituren verarbeiten – ohne Anspruch auf perfekte Note-für-Note-Übereinstimmung.

**Eingänge:** Nur Audio (MP3/WAV); Audio + MIDI; nur MIDI.  
**Standard-Arbeitsmodus:** Musikalisch ausgewogen.  
**Startumfang:** Klaviersolo. **Referenzfall:** „Graziler Tanz“ (Suno-Audio + ursprüngliche MIDI-Transkription).

Projektstatus: Planung; noch keine implementierte oder getestete App. Siehe [Pflichtenheft](PFLICHTENHEFT_V0.1.md), [Projektstand](PROJECT_STATE.md) und [Entwicklungsanweisungen](AGENTS.md).
